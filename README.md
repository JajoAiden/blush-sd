# Blush Website Starter

A responsive one-page website concept for **Blush**, built from scratch using the visual direction shown on the client's Instagram account.

## Included
- Elegant blush, cream, wine, and soft-pink color palette
- Responsive desktop and mobile navigation
- Hero, About, Services, Portfolio, Process, Inquiry, and Footer sections
- Image placeholders that can be replaced with the client's full-resolution photos
- Working menu interactions and scroll animations
- Inquiry form layout ready to connect to Formspree, EmailJS, Netlify Forms, or another form handler

## Files
- `index.html`
- `styles.css`
- `script.js`

## Replace images
Each placeholder is currently a `<div class="image-placeholder">`.

To use a real image, replace it with:

```html
<img src="images/your-photo.jpg" alt="Describe the floral arrangement">
```

You can also keep the existing container and add a CSS background image.
